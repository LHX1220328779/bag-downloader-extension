# 数据包回传与下载助手 v2.5.7

用于 `http://10.198.92.173:8080` 的 Chrome/Edge 侧边栏扩展。保持纯插件，无需构建或安装本机程序。

## 安装与升级

使用 Chrome、Edge 或 Chromium 120+，在扩展管理页开启开发者模式，加载包含 manifest.json 的项目目录。已有版本在原目录更新后点击“重新加载”，已打开的目标网页会自动恢复捕获，也可刷新网页；不要卸载扩展或清除存储。任务数据保存在使用者自己的浏览器中，不随安装包分享。

本版修复“回传”开关在异步刷新后自动重新勾选的问题：点击立即改变选择，用户选择独立持久保存，不被目录检查或旧进度快照覆盖。等待保存或服务器确认时，按钮显示刷新标识；接口失败显示原因并自动重试，保留用户选择。关闭暂停本任务已经建立的回传并停止追加，开启恢复原记录并继续追加未提交数据包。保留 2.5.6 的原记录控制、2.5.5 的目录创建错误诊断、2.5.4 的车辆容量恢复和 2.5.3 的目录授权恢复。沿用原有权限；scripting 仅用于插件重载后为已打开的目标网页恢复筛选捕获。旧任务保留原 ID、运行代次、回传记录、目录、下载后端及原生下载 ID，不因选择新目录而迁移或取消。Chrome 侧边栏顶部由浏览器提供的扩展名称和控件无法通过标准 sidePanel 接口隐藏。

## 创建任务

1. 在目标网页选择车辆、矿区、英文包类型及来源。切换到 `/search` 或 `/table` 后，侧栏跟随当前页面筛选。监听四项表单值及选择事件，500 ms 轮询补漏；激活、导航及插件重载自动核查桥接。多个网页打开时只采用当前活动目标页，过期序号或路由快照不覆盖新选择。
2. 在“目录设置”直接粘贴或编辑完整本地保存路径，也可选“最近目录”。路径按车辆记忆；不再需要先更换目录，再单独填写显示路径。
3. 首次使用该路径时，点击“创建任务”会打开系统目录窗口，请选择输入路径对应的实际目录并点击“选择文件夹”，随后在浏览器提示中允许编辑文件。浏览器无法按路径文本自动打开或验证绝对目录；系统窗口中的选择决定实际位置。插件将完整路径与该实际目录绑定，授权有效时后续创建直接复用，不再弹出目录窗口。新路径不会按相同末级目录名套用其他目录。
4. 设置起止年月日、时、分、秒。点击数字段会选中该段，可直接输入；只有右侧日历按钮打开详细弹窗。
5. 独立勾选“回传”和“下载”：仅回传、仅下载或同时进行。回传需要有效原因，Bug 号和备注可选；三项名称均显示在框内提示，框外不重复占位。仅回传无需选择下载目录。
6. 点击“创建任务”，再在任务卡片点击“执行”。创建区、任务及详情均可折叠，包名仅展示录制日期之后的部分。

界面采用苹果系统风格和系统字体，支持明暗主题。完整路径可以编辑、删除并持久记忆，刷新进度不会覆盖输入或移动光标。下载进度卡片省去顶部重复的当前包名，下方包状态列表保留；回传百分比显示整数。停止和删除需在当前任务卡片内二次确认；成功完成任务的执行、停止按钮禁用。

“回传”按钮用勾选表示开启，含回传的任务创建时默认开启。点击立即取消勾选并暂停回传；再次点击立即勾选并恢复回传，不需要二次确认。刷新标识表示选择正在保存或服务器尚待确认，等待时仍可再次点击改变选择。失败时显示重试原因，不能仅凭勾选判断服务器已生效。仅下载任务的回传按钮禁用。关闭回传仍可下载已入库数据包，任务完整路径、完成进度和运行代次保留。“停止”暂停本地调度和下载；任务已经停止时开启回传只恢复已有服务器记录，点击“执行”后才追加新回传。

## 目录隔离与授权

每个新下载任务固定自己的目录句柄 ID、目录名和创建时的完整路径标签。之后编辑路径或创建另一任务只影响新任务；原任务的目录 ID、完整路径、进度和运行代次保留。文件直接进入所选目录，不额外追加 bags，不创建 txt，不启动下载位置探测。

相同名称的目录按 `FileSystemDirectoryHandle.isSameEntry` 核查真实身份，例如两处都名为 rtfbag 的目录保持独立。再次选择同一实际目录复用原句柄记录；旧别名按同一写入目标处理，不替换旧任务 ID 或完成凭据。不同目录可以并发下载同名包，同一目录同名包只分配一个写入者；文件完整落盘后其他任务复用完成文件。停止、删除、失败或授权失效只影响对应任务或实际目录。写入锁释放后立即检查其他可执行队列，不等待下一次心跳。

句柄保存在扩展源的 IndexedDB 中。授权有效时直接复用；只有准备启动文件读写时才检查目录，活动下载流、等待服务器数据、已完成和已停止的任务不会因为心跳刷新再次显示授权。浏览器已保留持久访问权限时，后台文档尝试静默恢复；后台没有用户手势，普通权限不足不会由定时器弹出系统授权框。确实需要用户授权的活动任务才显示“授权本任务目录”，点击后自动继续原进度，运行代次、回传锁及完成记录不清空。创建区仍在首次创建时选择对应目录。

目录记录缺失、实际目录断开或删除、系统拒绝访问和数据库读取故障分别记录原因，显示目录不可用而不是浏览器重新授权。数据库连接意外关闭时自动重开一次；确认事务中止、写入已回滚后，也仅重试一次，不重复已提交的写入。临时故障每 30 秒自动重查，真实权限等待每分钟尝试恢复，同一原因不会反复追加日志；日志记录原始错误、权限状态和后台恢复结果，故障恢复后继续原任务。回传和其他目录的下载仍继续。Chrome/Edge 的持久目录权限由浏览器和用户选择决定；没有授予持久访问或权限被撤销时，纯插件不能强制恢复，因此不能保证所有浏览器都永久免确认。

### 创建时的目录错误

目录选择 API 的 `AbortError` 可能表示取消，也可能表示浏览器拒绝敏感目录或未授予指定访问权限，不能据此认定用户取消。选择后写入授权未通过、目录记录保存失败、路径绑定失败分别显示原因，任务只在目录绑定和写入权限核查成功后创建。

目录选择成功后的后续步骤失败时，本侧栏保留该次选择，再次点击“创建任务”复用对应完整路径的目录。选择未完成或侧栏已关闭且目录记录未保存时仍需重新选择。错误下方可“复制错误详情”，包含版本、浏览器信息、完整路径、失败步骤、权限状态和原始错误；最近一条保存在使用者自己的扩展本地存储，成功创建后清除。

历史原生浏览器下载任务仍使用原生下载管理器及原目录，不自动改成句柄模式。它们继续支持默认目录等于原目录或是其上级时按相对路径保存。旧任务在浏览器默认目录之外时仍会等待目录；需要到 `chrome://settings/downloads`（Edge 对应设置页）恢复兼容位置。创建新任务不再参与这一全局设置。旧原生任务恢复下载 ID 时同时核查任务完整目录，同一 URL 或同名包在另一位置的记录不能复用；历史误关联记录只解除关联，不暂停其他任务的下载。旧原生任务与新句柄任务遇到同名包时保守串行，避免无法从路径标签证明目录身份时同时写入；不同新句柄目录仍可并行。

## 持久化、下载与完整性

任务、队列、完成进度、运行代次、回传记录及目录选择持久保存。关闭侧栏不停止任务；浏览器重新打开后恢复活动任务。目录模式通过后台 offscreen 文档流式接收文件，只有精确长度一致且任务仍有效时才原子提交；网络中断、停止或写入失败不提交部分内容，也不替换已有完整文件。

目录模式的完成凭据包括目录 ID、包名、服务器路径、精确大小和文件修改时间。重启后仅对仍在执行的任务核查真实文件及凭据，完整文件不重复 GET。成功完成的任务保持完成，升级会恢复旧版本尚未启动读写、仅因自动核验而等待授权的完成任务。无凭据的旧文件用服务器 HEAD 精确长度核验；零字节、截断、缺失或未知长度不能跳过。扩展重载或关闭浏览器会中断目录模式的流连接，恢复后从尚未完整的包重新下载；本版不保存该包的部分字节作为断点。已完整包和其他任务的完成进度保留。

网络中断、连接超时及服务器临时错误保持待重试，采用最多一分钟的退避，不计入永久失败次数；网络恢复后继续原任务。正确目录中可恢复的旧原生下载继续原 ID，错误位置的残缺记录不能复用；无法恢复的残缺包重新下载到原目录，已完整文件不重复下载。

新目录模式使用 fetch 与目录流写入，不调用浏览器下载 API，因此不会展开浏览器下载列表，也不干预其他下载提示。历史原生任务保留共享静默控制：原下载 ID 优先恢复，Chrome 报告 complete、exists 且 fileSize、bytesReceived、totalBytes 与精确服务器长度一致才完成。历史原生下载在扩展重载时不取消，不能恢复的未完整包才重试。

保留扩展存储和浏览器下载记录以维持旧原生恢复能力。停止暂停本地任务；删除移除本地任务记录并取消未完成下载，保留完整文件。服务器回传由“回传”开关独立控制。目录句柄权限由浏览器决定，不能承诺重启后永不再授权。

## 时间覆盖规则

包名日期是录制开始时刻；连续下一包的起点用于证明当前包的结束边界。选包包含覆盖任务起点的前一个包，以及覆盖结束秒所需的所有包。终点之后的下一包只作为边界证据，不提交或下载。

例如 `2026-11-06 08:39:20 → 08:42:50`，若包序列从 `08:38:55_193` 每 30 秒递增到 `08:42:55_201`，执行目标为 193–200；194 的 `08:39:25` 不能作为首包，201 仅证明 200 覆盖末端。

起点前的候选包必须先证明与所选范围重叠，才进入执行队列。归档比 MDC 清单先返回时，不把较早旧包错误纳入目标。候选包或末包缺少可靠后继时，只读前 4 KB RTFBAG 文件头确认实际录制结束时间，不把几天后的包当作连续证据。起点缺失、中间序号跳跃、范围内连续性不明或末包未覆盖终点时，显示覆盖告警及浏览器通知。能够识别的目标继续处理，缺失数据持续核查；不将任务误标成功完成。

历史误选包经边界确认不属于范围后，从目标及进度计数中排除，保留原记录、完整文件和在途进程，不再纳入新队列；历史误告警标注“已纠正”。接口写入时间不能代替录制时间。

## 回传与告警

回传按录制时间升序创建，每批最多 10 个包，同矿区同车辆串行提交，不同车辆可以并行。提交队列独立运行，慢提交仍能查询车辆在线状态和归档文件。服务器已接受或提交结果不明的包持续核查原回传及成功记录，不因车辆掉线重连、重载或再次执行自动重建。仅回传可用精确成功记录确认完成；同时下载时等待归档入库。

站点明确拒绝提交并提示“车辆回传任务较多”时，未被接受的包回到待提交状态，按 30 秒、1 分钟、2 分钟、4 分钟、最多 5 分钟退避，由后台轮询自动继续，不计为永久失败。同车其他任务等待至少 30 秒，其他车辆和矿区继续。拒绝过的包逐个追加，使少量空位也能继续利用；遇到容量拒绝即停止本轮后续批次。重试前先查询服务器记录，已经接受或成功的包不重复提交；网络超时和其他未知结果继续保留提交锁。完成任务清除同车容量等待标记，避免旧时间戳在系统时钟回拨后阻塞新任务。

升级后会先核查旧版保留的容量报错，仅对未被服务器接受且明确属于容量拒绝的条目恢复自动重试。已公布文件名的记录只确认对应文件，同一分钟其他包和仅有批次标记的成功/失败记录不会错误锁住待提交包。进度中的“已提交”只统计已确认接受或已完成的条目，容量等待有单独说明。

车辆 MDC/NAS 不可用时暂停新提交，已归档包仍可下载。恢复在线自动继续；浏览器通知与图标角标保留，网页内不插入顶部告警横幅。下载失败最多尝试 3 次，之后显示可重试状态；已提交回传异常继续核查。如需重试未确认的回传，先停止任务并在网站核实，再使用日志与恢复入口。

回传开关通过网站的 `/api/break/pause/{record_no}` 和 `/api/break/cancelpause/{record_no}` 暂停、恢复原记录，保留进度；成功回传的包不重复创建。关闭时先保存选择并阻止新的 mdcadd，再暂停所有可确认由本任务建立的未完成记录，包括多批次和在途提交晚到。依据任务、单包或已保存批次标记确认归属并核查车辆/来源/矿区；同名包、同一分钟或仅匹配到的外部 recordNo 不构成控制依据，不影响其他任务及手工回传。

按钮表示用户选择，下方显示服务器确认状态。独立的 taskTransferSelections 只在创建、明确切换和旧任务初始化时写入，进度刷新只读取；每次点击携带请求编号并确认保存版本，慢目录检查、旧快照和迟到的旧回复不能改回选择。接口失败或查询失败显示未完成并自动重试，不误报全部暂停；请求生效但响应丢失时先查询确认。快速反向点击按最新选择补偿已发出的相反命令。开关与命令记录持久保存，本地停止后或插件重载后继续核查未完成控制。旧任务按原单包/批次标记兼容；无法证明归属的历史记录不会被误操作。

升级默认保留开启，但在用户首次操作开关前不自动恢复网站手工设置的 pause。首次操作后持续执行用户的开关选择，不通过重新 mdcadd 恢复已接受回传。站点 MDC 新建回传来源固定为 mdc，回传要求来源为 mdc 或不限；仅下载支持其他来源。

```sh
npm test
npm run check
BAGFLOW_PLAYWRIGHT_MODULE=/absolute/path/to/node_modules/playwright-core npm run check:browser

```

Node.js 20+ 仅用于开发检查。测试使用模拟 API、本地业务夹具及隔离 Chromium，不发送真实车辆回传或下载真实大包。覆盖回传开关、即时选择与刷新标识、异步目录加载竞态、旧快照覆盖、原记录恢复、外部回传隔离、快速切换、迟到提交与控制重试；目录身份、并发隔离、停止/删除竞态、授权恢复、完整性、回传去重、容量退避与逐包追加、旧容量报错恢复、时间边界、扩展重载、浏览器关闭重开、明暗主题、300/380/720px 布局及滚动节点保留。

新模式的浏览器测试模拟系统 picker 返回两个真实 OPFS 目录句柄，实际执行 IndexedDB 持久化、isSameEntry、Web Locks、后台调度和文件流写入。权限失效和服务器暂停/恢复业务使用受控夹具，自动验收不发送生产回传写请求。原生系统目录选择及授权弹窗视觉、外部目录的权限跨重启保持、Windows/Edge、系统通知 UI 和电脑硬重启尚未实机验证；OPFS 结果不能作为这些条件的保证。旧原生静默通过真实 Chrome API 调用及下载事件验证，headless 验收不等于原生下载气泡视觉验收。

用户真实 Chrome 的限定任务实验见[回传开关验证记录](https://github.com/LHX1220328779/bag-downloader-extension/blob/main/docs/transfer-switch-verification.md)。运行中的旧后台对回传切换返回“未知指令”；v2.5.7 尚需加载新后台后进行真实暂停恢复验收。
